# BLACK 0.5.0: controls, devices and button pictures

An experimental native macOS release of **BLACK for Original Xbox** for Apple Silicon.
Bring your own supported USA or European disc image. No game data is included.

## What's new

- **One Controls menu.** Device selection and button prompts are the first two rows,
  visible without scrolling. Bindings, mouse response and gamepad response have
  separate pages; calibration and driver options move under Advanced. Back returns
  to the previous row, and each reset affects its named page or binding list.
- **Saved device selection:** Auto, Gamepad or Keyboard and Mouse. Auto follows
  deliberate input; mouse motion alone does not take control away from a gamepad.
  Switching to keyboard restores relative mouse capture during play or after settings.
- **Controller button bindings.** Reassign or clear 16 logical Xbox button/trigger
  controls. The shared editor also retains two keyboard/mouse bindings per action.
  Choosing which list to edit does not change the device used for gameplay.
- **Drawn button prompts.** Auto, Xbox, PlayStation or Keyboard, chosen independently
  of gameplay input. Face buttons, shoulders, triggers, sticks, keycaps and mouse
  buttons use pictures shared with the settings panel. Hints follow saved bindings.
  The private font view and host atlas leave source game files intact.
- **Independent X/Y response.** Mouse and gamepad pages group Look and Aiming into
  pairs without changing existing values. Select an axis, press Enter to adjust it,
  then Enter or Back to finish.
- **Intro skipping after weapon previews.** Menu weapon films no longer disable
  the later developer-credits and opening-film skip.
- README instructions and game-window settings captures reflect the new menu.

The setup, Russian game text and briefing subtitles from 0.4.x remain included.

## Install or update

1. Download **`BLACK-0.5.0-macos-arm64.dmg`**.
2. Drag **BLACK.app** to **Applications**, replacing the previous app, then open it.
3. Existing Library game data, preferences and saves remain in place. New input
   settings default to Auto with the original controller mapping. New installations
   start the first-time setup for your own disc.

Open settings with **F1/F10**, **Cmd+,** or **Back + Start** (Share + Options).
Choose **Controls**. Game menus keep their physical confirm/back buttons even
when gameplay buttons are rebound. Action labels assume BLACK's default game layout.

**Requirements:** Apple Silicon and **macOS 27 or later**. The app is **ad-hoc signed,
not notarized**. If macOS blocks it, check the download source and use
**System Settings → Privacy & Security → Open Anyway**.

## Validation and limits

On **Apple M1 Pro / macOS 27.0.1**: **110 CTest checks**, GPU readback/colour probes
and **43 Python tests** passed. The native menu checks cover editor scope,
independent X/Y values, scoped resets, capture/cancel/disconnect and return/focus
navigation. English/Russian layouts were inspected at 960×600 and 640×480.
Muted scripted runs displayed PlayStation prompts, loaded the first mission and
exited normally. The user confirmed physical device/prompt switching before the
final mouse-capture and menu changes. The final DMG app was launched read-only
from its mounted image in English and Russian, with a system-only PATH and no
DYLD_LIBRARY_PATH. Both settings-menu runs quit normally with code 0 before their
limits; private font views were removed and source game files/user preferences
were preserved.

Physical reacceptance of mouse look, controller rebinding, rumble and USB/Bluetooth
hotplug remains open. Scripted input and dummy audio do not qualify hardware or
real audio. Full-game stability, every checkpoint, other game control presets,
a clean second Mac, Intel Macs, Linux and Steam Deck are not qualified.
