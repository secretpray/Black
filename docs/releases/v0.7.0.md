# BLACK 0.7.0: checkpoints between launches

An experimental native macOS update of **BLACK for Original Xbox** for Apple
Silicon. Bring your own supported USA or European disc image; no game data is
included.

## New

- **Checkpoints kept between launches.** BLACK writes the game's own checkpoint
  beside the saves when it is reached, for each saved profile slot, mission and
  difficulty. **Continue Mission** on the title resumes it after quitting, with
  health, ammunition, weapons and objectives as they were. While it is shown,
  the game's own button reads **Start Mission**: it opens the mission list and
  starts the chosen mission from its start.
- **Restart from the checkpoint.** F9 or Back + Y in a mission ask first, in the
  pause page's style, then go back to the last checkpoint of the run.
- **As on the console otherwise.** The game's own Restart in the pause and
  Mission Failed menus starts the mission over and removes its checkpoint, and
  completing a mission retires the profile's checkpoints. Death and Continue
  still use the game's own checkpoint.
- **Checkpoints follow Autosave.** Without the game's Autosave they are neither
  written nor restored. **Options → Profile** gains a **Checkpoints On / Off**
  row under Autosave, the same switch as **Saves → Save Checkpoints** (on by
  default); a slot's page shows its checkpoint and can delete it.
- **Display Brightness and Display Gamma** on General, over the game's own
  brightness and fades: the black level and the midtones, live. At 0 and 1.00
  the picture is exactly the game's.

Everything from 0.6.1 and earlier remains. Settings and saves carry over;
checkpoints start with this version.

## Install or update

Download **`BLACK-0.7.0-macos-arm64.dmg`**, drag **BLACK.app** to **Applications**
and replace the old app. Existing Library game data, settings and saves remain
in place. When the game first reads your profile, BLACK backs it up if it changed since the last backup.

**Requirements:** Apple Silicon and **macOS 27 or later**. The app is **ad-hoc
signed, not notarized**. If macOS blocks it, check the source and use
**System Settings → Privacy & Security → Open Anyway**.

## Validation and limits

On **Apple M1 Pro / macOS 27.0.1**, on a copy of the user's saves with scripted
input: Continue Mission resumed mission 2 at its checkpoint; Back + Y in that
mission asked, and Restart from Checkpoint went back to the same place; the
Profile options row switched On and Off, left the menu's navigation while
Autosave was off and came back with it, in English and Russian. Earlier the user
resumed from the title item by hand. **121 CTest checks** and **49 Python
tests** passed, among them capture, restore, both restarts, a damaged file and a
profile save during a session on a synthetic mission. The final DMG was checked
read-only in English and Russian with isolated data and system-only PATH: both
opened the settings and quit normally, and source game files and user
preferences kept their hashes. The matching source archive was verified without
game or private data.

Not checked: a checkpoint reached in normal play on every mission and
difficulty, death and the game's own Continue after a resume, the game's own
Restart removing the checkpoint, F9 on the keyboard and Back + Y on a physical
controller, and Display Brightness / Gamma judged in missions. Other limits of
0.6.1 still apply.
[Validation](https://github.com/secretpray/Black/blob/v0.7.0/docs/VALIDATION.md).
