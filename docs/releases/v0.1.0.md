# BLACK 0.1.0 — macOS / Apple Silicon

The first experimental native macOS release of **BLACK for Original Xbox**.
Bring your own supported USA or European disc image. No game assets are included.

## Install or update

1. Download **`BLACK-0.1.0-macos-arm64.dmg`**.
2. Drag **BLACK.app** to **Applications**, then open it.
3. Choose your own Original Xbox BLACK ISO/XISO or extracted disc folder.
   The app checks the revision and installs a private copy without changing the source.

**Requirements:** Apple Silicon and **macOS 27 or later**. This first binary's
bundled libraries require macOS 27; older macOS versions are not supported by this download.
No Homebrew or Python is needed to run the app.

The app is **ad-hoc signed, not notarized**. If macOS blocks it, check the download
source and use **System Settings → Privacy & Security → Open Anyway**.

Installed game data, settings and saves live in `~/Library/Application Support/BLACK/`.
Replacing the app leaves that data intact. Development-launcher data in `out/`
is separate and is not automatically migrated.

## Included

- Native ARM64 host, NV2A rendering through ANGLE Metal and the DSP audio path.
- A BLACK-styled installer DMG, full-size app icon and Applications integration.
- Native fullscreen and Game Mode opt-in, with activation controlled by macOS.
- Saved render scale/FOV, SMAA/FXAA, anisotropic filtering and MetalFX spatial upscaling.
- TGP-inspired recomp settings with Controller and Mouse and Keyboard pages.
- Independent stick/trigger deadzones, drift measurement, live axes, look/aim X/Y
  sensitivity, hold-to-aim, aim assist and rumble intensity.
- Direct mouse look, two action bindings, Flash menu cursor and keyboard name entry.
- Profile save/load evidence and fixes for audio completion, IRQ handoff and NV2A FIFO races.

**Settings:** F1/F10, Cmd+, or Back + Start. **Fullscreen:** Cmd+Return.
**Quit:** Cmd+Q. [Quick start and controls](https://github.com/secretpray/Black#quick-start).

## Compatibility and limits

Tested on **Apple M1 Pro / macOS 27.0.1**. Combat, game menus and profile saving
have been exercised, but a complete playthrough is not qualified. Remaining
runtime races, long frames, audio quality and physical controller calibration,
rumble/hotplug need broader testing. Gameplay keeps the original fixed step
paced near 30 Hz; stable 60 FPS and unlocked-FPS physics are not promised.
Linux, Steam Deck and Intel Macs are not qualified.

100 CTest checks, 30 Python checks and GPU probes passed. The autonomous app
ran with system-only PATH and bundled dylibs, and the Applications copy exited
normally before its limit. Muted checks do not qualify actual audio.
[Detailed validation and limits](https://github.com/secretpray/Black/blob/Black/docs/VALIDATION.md).

## Optional materials

- **`optional-library-sources.tar.xz`** — exact runtime/game-host/DSP sources,
  local overlays, library source archives and build/relink recipes.
- **`SHA256SUMS`** — download integrity checks.
- GitHub's automatic **Source code** archives are source snapshots, not playable apps.

No ISO, original XBE, game assets, generated game C, private saves or session logs
are included in the release. You must supply your own supported game disc.
