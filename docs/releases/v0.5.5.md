# BLACK 0.5.5: steady frame rate, bloom and sun shafts

An experimental native macOS update of **BLACK for Original Xbox** for Apple
Silicon. Bring your own supported USA or European disc image; no game data is
included.

## Fixed

- **Frame rate falling to 15-18 fps in later areas.** After a mission streamed
  in its next part, the game could drop from 30 fps and stay there, even after
  turning HD textures off. BLACK reads its depth buffer as a colour texture and
  reuses small colour targets as the depth buffer of its light passes. The
  emulated GPU had no direct path for either case and copied each one through
  game memory at the render scale, every frame. Both directions are now
  converted on the GPU in the Xbox's own byte layout, and the first mission
  holds 30 fps to the end.
- **Bloom and sun shafts.** The same copy lost the bright glare in doorways and
  windows and the shafts of sunlight. They now render where the Xbox shows them:
  the glare in the first mission's opening gate matches the original.

### Also since 0.5.3 (from 0.5.4)

- **PRESS START, the copyright line and the logo on the title screen.** Since the
  first macOS build only two bracket lines showed there. An old "menu black
  panel" workaround in the pinned host removed the depth mask the menu draws
  them in; BLACK now turns it off. The main menu, mission select, options,
  operator profile and pause menu show no black panel.

Everything from 0.5.3 and earlier remains: the HD texture alpha fix, controller
hotplug over USB and Bluetooth, a Bluetooth DualSense that answers sooner after
the desktop, and the HD pack check with folder selection. No settings or save
migration is required.

## Install or update

Download **`BLACK-0.5.5-macos-arm64.dmg`**, drag **BLACK.app** to **Applications**
and replace the old app. Existing Library game data, settings and saves remain
in place.

**Requirements:** Apple Silicon and **macOS 27 or later**. The app is **ad-hoc
signed, not notarized**. If macOS blocks it, check the source and use
**System Settings → Privacy & Security → Open Anyway**.

## Validation and limits

On **Apple M1 Pro / macOS 27.0.1** the user played the whole first mission with
the fix: no slowdown, bloom and sun shafts where they belong, no artefacts seen.
Of 1190 frame-rate samples in that run one was below 25 fps, while a part of the
level loaded. **114 CTest checks** and **49 Python tests** passed. The final DMG
was checked read-only in English and Russian with isolated data and system-only
PATH: both opened settings and quit normally, and source game files and user
preferences kept their hashes. The matching source archive was verified without
game or private data.

Missions 2–8 were not played through with the new conversion, and HD alpha in
missions 3–8 has not been checked by eye. Other limits of 0.5.3 still apply.
[Validation](https://github.com/secretpray/Black/blob/v0.5.5/docs/VALIDATION.md).
