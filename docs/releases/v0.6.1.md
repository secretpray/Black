# BLACK 0.6.1: working saves, a Saves manager and the Mac window

An experimental native macOS update of **BLACK for Original Xbox** for Apple
Silicon. Bring your own supported USA or European disc image; no game data is
included.

## Fixed

- **Saved profiles.** After the first profile list, Load Profile said there were
  no profiles and Save Profile showed all three slots as damaged, although the
  profile on disk was intact. The runtime resumed an old directory scan when the
  game reused a file handle; closing a handle now ends its scan. Saving can also
  reserve file space, as on the Xbox.
- **Name keyboard.** The B button shown on DELETE backed out of the page. On a
  pad X now deletes (held, it repeats), Y types a space and Start presses DONE,
  and the hints show those buttons.
- **Menu repeat.** A held direction raced past items because the game counts
  frames and its menus run at about 60 fps here. It now steps once, then every
  150 ms after 400 ms.

## New

- **Saves** in the settings. The three operator profiles with their progress; a
  slot's page shows its missions, replaces or fills it from a zip, a save folder
  or a profile file, exports it, and deletes or clears it as a console writes an
  empty slot. The slot the game autosaves to is greyed out, every change asks
  Yes or No and keeps a backup, and backups can be restored or moved to the
  Trash. Only saves on this Mac are used.
- **The settings as the game's menu.** General, Controls, Mods and Saves open
  their pages, Back climbs one level, and the selected item is described under
  the list, beside the game's rail band at its own place and type size. Y /
  Triangle or Backspace resets a setting, a page's last row resets the page, and
  Reset All Settings is on General. Close the Menu sits above Quit Game.
- **The Mac window.** Its size, place and full screen are remembered between
  launches; on a monitor that is gone it comes back centred, and a window too
  large for the screen shrinks to fit. Hide BLACK (Cmd+H), Hide Others and Show
  All, and a Window menu with Minimize (Cmd+M), Zoom, Enter Full Screen
  (Ctrl+Cmd+F) and Bring All to Front.

Everything from 0.6.0 and earlier remains: the game's brightness and fades, the
Home button, skipping films, steady frame rate in later areas, bloom and sun
shafts, HD texture alpha and controller hotplug. Settings and saves carry over;
the app opens full screen until you leave full screen once.

## Install or update

Download **`BLACK-0.6.1-macos-arm64.dmg`**, drag **BLACK.app** to **Applications**
and replace the old app. Existing Library game data, settings and saves remain
in place. When the game first reads your profile, BLACK backs it up if it changed since the last backup.

**Requirements:** Apple Silicon and **macOS 27 or later**. The app is **ad-hoc
signed, not notarized**. If macOS blocks it, check the source and use
**System Settings → Privacy & Security → Open Anyway**.

## Validation and limits

On **Apple M1 Pro / macOS 27.0.1** the user loaded and saved profiles repeatedly
on a copy of their saves without damaged slots, deleted test slots and imported
a profile, then saw the game's own list match; used X, Y and Start on the name
keyboard and the d-pad repeat on a DualSense; and resized, moved, entered full
screen and relaunched with the window restored, Cmd+H and Cmd+M working.
**119 CTest checks** and **49 Python tests** passed. The final DMG was checked read-only in
English and Russian with isolated data and system-only PATH: both opened the
settings and quit normally, and source game files and user preferences kept
their hashes. The matching source archive was verified without game or private
data.

Not checked: imports of saves from other dumps than the user's, a monitor removed
between launches, Stage Manager and Spaces, and a full playthrough. Other limits
of 0.6.0 still apply.
[Validation](https://github.com/secretpray/Black/blob/v0.6.1/docs/VALIDATION.md).
