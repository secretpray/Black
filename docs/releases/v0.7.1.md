# BLACK 0.7.1: settings prompts as on the game's pages

An experimental native macOS update of **BLACK for Original Xbox** for Apple
Silicon. Bring your own supported USA or European disc image; no game data is
included.

## Changed

- **Settings prompts.** Select, Confirm and Back stand in a column under the
  description, one row apart, as on the game's own pages, with the buttons
  centred before the words. Select shows a cross where left and right change
  the value; Default stands beside Confirm, in the values' column. The heading
  and the list sit nearer the top of the screen.
- **Room to read.** Seven rows show and the rest scroll, so a row's space parts
  the list from the description, and the description's two lines no longer
  touch.

## Fixed

- **A slot's checkpoint** in Saves names the mission in campaign order and the
  checkpoint reached; it showed the game's level number and always part 1.

The README has new screenshots of the settings and of checkpoints.

Everything from 0.7.0 remains: checkpoints kept between launches, Continue
Mission on the title, restart from the checkpoint with F9 or Back + Y, the
Checkpoints row under Autosave, and Display Brightness and Gamma. Settings,
saves and checkpoints carry over.

## Install or update

Download **`BLACK-0.7.1-macos-arm64.dmg`**, drag **BLACK.app** to **Applications**
and replace the old app. Existing Library game data, settings and saves remain
in place. When the game first reads your profile, BLACK backs it up if it changed since the last backup.

**Requirements:** Apple Silicon and **macOS 27 or later**. The app is **ad-hoc
signed, not notarized**. If macOS blocks it, check the source and use
**System Settings → Privacy & Security → Open Anyway**.

## Validation and limits

On **Apple M1 Pro / macOS 27.0.1** the General page was checked in a scripted
run. **121 CTest checks** and **49 Python tests** passed. The final DMG was
checked read-only in English and Russian with isolated data and system-only
PATH: both opened the settings and quit normally, and source game files and
user preferences kept their hashes. The matching source archive was verified
without game or private data. The limits of 0.7.0 still apply.
[Validation](https://github.com/secretpray/Black/blob/v0.7.1/docs/VALIDATION.md).
