# BLACK 0.5.1: vibration, menu audio and input fixes

An experimental native macOS update of **BLACK for Original Xbox** for Apple
Silicon. Bring your own supported USA or European disc image; no game data is
included.

## Fixed

- **Controller vibration works.** Game motor feedback now reaches SDL, and the
  game's enable flags follow Controls after profile loads. Intensity and the
  off switch apply; changing vibration in the original Options/Pause menu also
  updates the port setting. Version 0.5.0 acknowledged requests without driving
  the motors.
- **Speech stops looping in recomp settings.** Game audio fades to silence
  while the menu pauses gameplay. Closing it clears queued silence and fades
  audio back in.
- **Input returns immediately after the desktop.** The window restores its
  game/menu responder and relative mouse capture, clearing stale input blocking.
- **Mouse fire after gamepad switching.** A previous menu/controller can no
  longer keep the newly selected device's buttons blocked while mouse look works.

The Controls menu, drawn button prompts, Russian text/subtitles and setup from
0.5.0 remain included. No settings or save migration is required.

## Install or update

Download **`BLACK-0.5.1-macos-arm64.dmg`**, drag **BLACK.app** to **Applications**
and replace the old app. Existing Library game data, settings and saves remain
in place. First-time users supply their own supported disc through setup.

**Requirements:** Apple Silicon and **macOS 27 or later**. The app is **ad-hoc
signed, not notarized**. If macOS blocks it, check the source and use
**System Settings → Privacy & Security → Open Anyway**.

Open recomp settings with **F1/F10**, **Cmd+,** or **Back + Start**
(Share + Options), then choose **Controls**.

## Validation and limits

On **Apple M1 Pro / macOS 27.0.1**, the user physically confirmed Bluetooth
DualSense vibration/on-off, mouse look and fire after gamepad switching,
immediate input after desktop return, and corrected speech/menu audio behaviour.
One physical Reload-to-Square binding was also checked and restored.

**113 CTest checks**, GPU readback/colour probes and **43 Python tests** passed.
The menu-audio check used real game PCM with a dummy audio device: its pre-mute
mix was nonzero while the accepted output was silent, followed by normal quit.
That automated check does not qualify actual audio; the user's listening test
is separate. The final DMG was checked read-only in English and Russian with
isolated data, system-only PATH and no DYLD_LIBRARY_PATH. Both runs opened
settings and quit normally before their limits; source game files and user
preferences retained their hashes. The matching source archive and checksums
were verified without game or private data.

**USB/Bluetooth hotplug remains unverified.** Other controllers, analog trigger
rebinding, every control preset/effect, a complete playthrough, all saves/races,
overall audio quality and a clean second Mac remain open. Intel Macs, Linux
and physical Steam Deck are not qualified.
