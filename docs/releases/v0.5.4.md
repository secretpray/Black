# BLACK 0.5.4: title screen text

An experimental native macOS update of **BLACK for Original Xbox** for Apple
Silicon. Bring your own supported USA or European disc image; no game data is
included.

## Fixed

- **PRESS START, the copyright line and the logo on the title screen.** Since the
  first macOS build the title screen showed only two bracket lines where the
  Xbox shows PRESS START, and the copyright line and the title logo were missing.
  The game draws them inside a depth-only mask; an old "menu black panel"
  workaround in the pinned host collapsed that mask to a point, so nothing inside
  it was drawn. With xemu's renderer the mask only writes depth, and BLACK now
  turns the workaround off. English and Russian text both show.

Everything from 0.5.3 remains: the HD texture alpha fix, controller hotplug over
USB and Bluetooth, a Bluetooth DualSense that answers sooner after the desktop,
and the HD pack check with folder selection. No settings or save migration is
required.

## Install or update

Download **`BLACK-0.5.4-macos-arm64.dmg`**, drag **BLACK.app** to **Applications**
and replace the old app. Existing Library game data, settings and saves remain
in place.

**Requirements:** Apple Silicon and **macOS 27 or later**. The app is **ad-hoc
signed, not notarized**. If macOS blocks it, check the source and use
**System Settings → Privacy & Security → Open Anyway**.

## Validation and limits

On **Apple M1 Pro / macOS 27.0.1** the title screen was checked in English and
Russian with the HD pack, and the user confirmed it live. The main menu, mission
select, options, operator profile and the pause menu show no black panel.
**114 CTest checks** and **49 Python tests** passed.
The final DMG was checked read-only in English and Russian with isolated data and
system-only PATH: both opened settings and quit normally, and source game files
and user preferences kept their hashes. The matching source archive was verified
without game or private data.

HD alpha in missions 3–8 has not been checked by eye. Other limits of 0.5.3 still
apply. [Validation](https://github.com/secretpray/Black/blob/v0.5.4/docs/VALIDATION.md).
