# BLACK 0.4.1 — Russian film subtitles

An experimental native macOS release of **BLACK for Original Xbox** for Apple Silicon.
Bring your own supported USA or European disc image. No game assets are included.

## What's new

- **Russian subtitles in the briefing films.** With Russian game text, the films before
  each mission show Russian subtitles. The nine tracks come with the app and turn on
  by themselves; other languages are unchanged.
- **Wider Cyrillic in the setup.** РУССКИЙ and other text the game's fonts cannot
  draw now use the same wide faces as the settings panel, not a narrow stand-in.

Everything else is as in [0.4.0](https://github.com/secretpray/Black/releases/tag/v0.4.0):
the first-time setup, Russian game text built into your own copy, and the game's menu
look for the settings panel.

## Install or update

1. Download **`BLACK-0.4.1-macos-arm64.dmg`**.
2. Drag **BLACK.app** to **Applications**, replacing the old app, then open it.
3. A new install starts the first-time setup. An existing installation, settings and
   saves are kept; with Russian already chosen the subtitles appear from this launch.

**Requirements:** Apple Silicon and **macOS 27 or later**. The app is **ad-hoc signed,
not notarized**. If macOS blocks it, check the download source and use
**System Settings → Privacy & Security → Open Anyway**.

## Tested

On **Apple M1 Pro / macOS 27.0.1**: with Russian chosen in setup and films not
skipped, the first mission's briefing film loaded its 35 subtitle cues and showed them
in time with the film, confirmed by eye. The other eight tracks were checked as files
(UTF-8, ordered times), not watched. The packaged app was run from its DMG. 106 CTest
checks and 43 Python checks passed.

**Limits** are those of 0.4.0: controller navigation in setup and dropping a file were
not tested by hand, Russian was checked in the first mission only, and a complete
playthrough, stable 60 FPS, Intel Macs, Linux and Steam Deck are not qualified.
[Validation and limits](https://github.com/secretpray/Black/blob/Black/docs/VALIDATION.md).
