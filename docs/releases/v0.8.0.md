# BLACK 0.8.0: a slot's record and mission results

An experimental native macOS update of **BLACK for Original Xbox** for Apple
Silicon. Bring your own supported USA or European disc image; no game data is
included.

## Added

- **A slot's record in Saves.** After each profile save BLACK keeps the mission
  last played, its difficulty, the time spent in missions, the date and a
  picture of the game from that run. A slot's page lists them under its rows,
  with the picture in the rail band beside them; the Saves list shows the
  selected slot's picture.
- **Mission statistics and best results.** Each mission run counts its time,
  deaths (Mission Failed's Continue and Restart), the checkpoints the game
  reached and its accuracy: the shots that hit a soldier, so fire at cover and
  vehicles counts as missed. Completed runs keep, per mission and difficulty,
  the best time, fewest deaths, best accuracy, the number of completions and
  the last run, shown under the selected mission in Saves → slot → Missions.

The record is kept beside the saves, in `Data/xboxrecomp/SlotInfo/`; the
profile is not changed. When it no longer matches the slot (an import, a
restore) the page shows the profile alone. Time and results count from the
first save made with 0.8.0.

## Fixed

- **Start Mission** on the title: while checkpoints are on, the game's own
  button reads Start Mission with or without a checkpoint. After a completed
  mission retired the checkpoint it went back to its own Continue Mission
  label, which opens the mission list.

Everything from 0.7.x remains. Settings, saves and checkpoints carry over.

## Install or update

Download **`BLACK-0.8.0-macos-arm64.dmg`**, drag **BLACK.app** to **Applications**
and replace the old app. Existing Library game data, settings and saves remain
in place. When the game first reads your profile, BLACK backs it up if it changed since the last backup.

**Requirements:** Apple Silicon and **macOS 27 or later**. The app is **ad-hoc
signed, not notarized**. If macOS blocks it, check the source and use
**System Settings → Privacy & Security → Open Anyway**.

## Validation and limits

On **Apple M1 Pro / macOS 27.0.1** missions 1 and 2 were played on the
developer's own data: the record and the results were written by real
autosaves and shown in Saves. **123 CTest checks** and **49 Python tests**
passed. The final DMG was checked read-only in English and Russian with
isolated data and system-only PATH: both opened the settings and quit normally,
and source game files and user preferences kept their hashes. The matching
source archive was verified without game or private data. A death answered
with Continue or Restart and a second completion of a mission were not played.
[Validation](https://github.com/secretpray/Black/blob/v0.8.0/docs/VALIDATION.md).
